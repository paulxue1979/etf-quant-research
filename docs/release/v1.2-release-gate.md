# ETF Quant Research System V1.2 Release Gate

## Release Scope

V1.2 adds chart-wide navigation and a versioned multi-strategy research comparison workflow. The approved scope is:

- synchronized base-100 TWR and drawdown comparison charts;
- categorized metrics with deterministic sorting;
- stable strategy colors, legend hide/show, focus mode, and Show All;
- compatibility states for comparable, warning, unknown, and incompatible runs;
- MAX, Fit All, Reset View, shared range, and shared crosshair controls;
- clearer stateful-strategy starting allocation and hold-previous behavior;
- discoverable one-time and monthly capital contributions;
- long-history and ten-run browser hardening.

The comparison wealth index is normalized to 100 at each run's first available point. It is a time-weighted strategy-performance view and does not replace Portfolio Value, Capital Invested, Profit, or investor XIRR. Drawdown is sourced from the canonical backend series. Compatibility warnings remain visible, and an incompatible result is not presented as a fair strategy comparison.

## Contribution And Stateful Semantics

Capital contributions are external cash flows, not strategy signals. A requested contribution enters Cash on its effective common trading date and is deployed only through the current strategy target and rebalance policy. TWR removes the timing effect of external cash flows; XIRR describes the investor experience.

Starting Allocation seeds a stateful strategy only before its first resolved target. HOLD_PREVIOUS keeps the most recently resolved target, does not reapply Starting Allocation, and does not create a synthetic signal. Signal execution remains `Signal(T) -> T+1 open`.

## Known Limitations

- The persisted 2000-present QQQ acceptance run has no persisted benchmark series. Benchmark and DCA report rendering were therefore verified with a separate real-data 2020-2025 run using SPY.
- The current research-history endpoint deserializes and sorts all stored runs before pagination; loading 129 large runs took about 16 seconds in this gate.
- The in-app browser viewport override did not apply during this gate. The 390x844 layout remains covered by the committed frontend tests and the preceding PHASE 10F browser acceptance, but was not freshly reproduced in PHASE 10G.
- The repository-wide Ruff format gate is not clean: `45 files would be reformatted`. Ruff lint passes, and this is pre-existing formatting debt outside the approved V1.2 scope.
- The Vite build retains the existing warning for a JavaScript chunk larger than 500 kB.
