## Browser Reproduction and Fix

Before the fix, Strategy Library showed `PEAK_DRAWDOWN_UAT_V141` r3, and the
Library click could read that exact Draft, but the editor URL stayed `/`.
Refreshing issued
`GET /strategy-lab/strategies/qqq-tqqq-sgov-dynamic-allocation/draft` and
received `404 STRATEGY_NOT_FOUND`; it then displayed the default unsaved
Strategy. `GET /strategy-lab/strategies/PEAK_DRAWDOWN_UAT_V141/draft` returned
200. No `draft_id` or `version_id` was involved in the failed request.

The hotfix persists `?draft=<strategy_id>` in browser history and restores
that exact Draft after refresh, browser restart and Back/Forward. Missing
Strategy, missing Draft, and Trashed lifecycle are shown without silently
substituting the default editor. A missing Draft may be created only by an
explicit user action. The backend's existing typed 404 contract is unchanged.
