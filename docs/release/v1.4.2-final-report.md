## Architecture and Security

Codex connects to a local stdio MCP process. It may read bounded Strategy and
Draft context and prepare typed semantic ChangeSets, but cannot apply Drafts,
save versions, execute research, Freeze, delete or use raw SQL/shell/filesystem
tools. The ETF Quant backend does not depend on `OPENAI_API_KEY`. Human approval
is through the local browser API; its Origin guard is not remote authentication.

Proposal bodies live separately from Strategy Drafts. Approval checks exact
revision/hash and replays operations under a rollback-journal transaction that
atomically persists the Draft and approval audit. Additive failure evidence is
written only after a non-committed attempt rolls back. `APPLIED` and `FAILED`
evidence cannot both be treated as valid. `FAILED` is terminal and readable by
the browser and MCP without giving Codex an apply tool.
