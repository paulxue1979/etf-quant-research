# ETF Quant Research System V1.3.1 Release Notes

## Overview

V1.3.1 is a UI/UX and research-authoring enhancement release built on the
frozen V1.3 strategy, accounting, backtest, research, and OOS contracts. It is
not a strategy-engine semantic rewrite.

## Highlights

### 12B Chart Improvements

- Full-history, Fit All, Reset View, and CUSTOM chart navigation remain under
  one shared viewport owner.
- Sibling financial charts preserve synchronized ranges and crosshairs.

### 12C Marker UX

- BUY/SELL, execution, rebalance, allocation, and regime marker categories
  remain filterable with grouped event details.
- Marker detail interaction does not take ownership of the chart viewport.

### 12D Timeframe / Relative Threshold

- Rule and condition authoring supports DAILY/WEEKLY operands and relative
  thresholds while preserving legacy payload omission semantics.
- Unknown fields, metadata, and schema versions remain round-trip compatible.

### 12E Visual Regime State Machine Editor

- Rule Based and Regime State Machine modes are available in Strategy Lab.
- The optional six-state template is:
  `PROTECTIVE`, `APPROACH`, `VALUE`, `DEEP_VALUE`, `RECOVERY_HOLD`, and
  `FULL_RISK_ON`.
- The default initial state is `PROTECTIVE`; the default protection path is
  `FULL_RISK_ON -> PROTECTIVE`, not `FULL_RISK_ON -> RECOVERY_HOLD`.
- State allocations, implicit Cash remainder, transitions, conditions, Value
  Zones, priorities, and validation are persisted through the existing domain
  payload.
- Flow layout is a projection; backend regime runtime remains authoritative.

## Compatibility

Existing V1.3 StrategyVersion records remain usable. Existing Rule Based and
Regime strategies load through the same Strategy Lab contract. Legacy missing
timeframe fields continue to use effective DAILY semantics without being
materialized during a no-edit round trip. Existing Regime payloads preserve
unknown fields, source metadata, schema version, states, transitions, and Value
Zones.

## Backend Semantic Freeze

V1.3.1 does not change Weekly completed-bar/no-lookahead semantics, signal
execution at `T+1` open, accounting, Regime runtime, Recovery Hold runtime,
Value Zone runtime, Position/Rebalance Policy, Grid Search, Selection/Freeze,
or Official OOS behavior.

## Migration / Upgrade Notes

No database migration is required. The product/package version is `1.3.1`.
Strategy schema, report schema, marker schema, and other internal contract
versions remain unchanged unless listed in the version matrix below.

## Known Limitations

- Real Tiingo DNS/HTTPS access is unavailable in the Codex execution
  environment; local Mac real-data acceptance remains the authoritative path.
- Vite reports the existing advisory about the main JavaScript chunk exceeding
  500 kB after minification. The build remains successful.
- MFE/MAE and holding drawdown remain unavailable where the existing report
  contract does not persist the required lot-level path.
