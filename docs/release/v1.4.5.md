# ETF Quant Research System v1.4.5

V1.4.4 feature code and its release tag are correct. At release time, the
Python package, frontend package, and FastAPI application version metadata
still reported 1.4.3. The operator health response also held a separate 1.4.3
constant.

V1.4.5 aligns the three application version declarations at 1.4.5 and reads
the operator backend version from the Python package metadata. A deterministic
test now fails with `VERSION_METADATA_MISMATCH` if the application versions
diverge. The bridge version remains 0.2.0.

No product semantics, database migration, Strategy behavior, or Backtest
behavior changed.
