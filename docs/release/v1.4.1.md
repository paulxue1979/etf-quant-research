# ETF Quant Research System v1.4.1

## Highlights

- Added `PEAK_DRAWDOWN` / 距前高回撤 as a Regime State Machine entry indicator
  for `VALUE` and `DEEP_VALUE` destination transitions.
- User-configurable drawdown thresholds can be combined with existing entry
  conditions through the existing OR condition tree.
- Peak calculation uses all real closing-price history available through the
  evaluation date, consistently using the StrategyVersion's `RAW_CLOSE` or
  `ADJUSTED_CLOSE` price field. It does not look ahead.
- Experiment Builder exposes the entry thresholds as semantic targets without
  changing the base StrategyVersion.
- Official OOS loads all-time-to-date history for active Peak Drawdown
  conditions, while returns, equity and other performance metrics remain
  restricted to the requested OOS evaluation interval.
- Freeze handoff responses now project nested immutable provenance into
  structured JSON, avoiding a committed Freeze followed by HTTP 500.

## Peak Drawdown Semantics

For the selected closing-price field:

```text
HistoricalPeak_t = max(Price_0, ..., Price_t)
PeakDrawdown_t = Price_t / HistoricalPeak_t - 1
```

The historical peak uses only real asset prices available on or before T. It
does not reset at the Backtest, IS or OOS start and does not synthesize prices
before asset inception. Peak Drawdown is entry-only in v1.4.1, and only for
transitions into `VALUE` or `DEEP_VALUE`. Existing MA/EMA/recovery conditions
continue to govern exits. The existing topology, one-active-state and
transition-priority rules remain unchanged.

Thresholds such as -20% and -30% are examples, not fixed defaults or engine
constants. A user may configure -18%, -28%, or other valid negative values;
the canonical representation uses fractions (for example, -20% is `-0.20`).

## Historical Data and OOS

Indicator context may start before the requested evaluation period, at the
asset's first available real price. Official OOS performance still starts and
ends within the frozen OOS range. In browser UAT, QQQ historical data began
on 1999-03-10, while official metrics covered 2024-01-02 to 2025-12-31.
The observed historical source was the existing real-data cache; this release
gate did not re-fetch Tiingo online.

## Compatibility

V1.4.1 does not change Rule Based execution, existing Regime topology,
`HOLD_PREVIOUS_ALLOCATION`, Strategy persistence, historical StrategyVersion
identity/hash, T+1 Backtest timing, human Selection, Freeze identity, or
Official OOS evaluation semantics. Nested immutable mappings remain immutable
in the domain; only API responses use a JSON-safe projection.

## Known Limitations

- Peak Drawdown is Regime-only, entry-only, and limited to `VALUE` and
  `DEEP_VALUE` destination transitions.
- No rolling 52-week, 250-day, three-year, or intraday-high variants.
- No automatic direct `APPROACH` to `DEEP_VALUE` transition.
- OR branch-level trigger attribution is not reported.
- Historical data may be served from the existing cache when the online
  provider is unavailable.
