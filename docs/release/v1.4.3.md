# ETF Quant Research System v1.4.3

## Highlights

- Fixed Strategy Library -> Open Draft identity and cold-load regression.
- Preserved the canonical `strategy_id` in the Draft URL so refresh, a new
  browser session, and browser Back/Forward restore the same Draft.
- Supported strategies without an independent Draft ID. The repository's
  `strategy_drafts.strategy_id` is the lookup key; `draft_id = null` in the
  Codex read model remains valid.
- Prevented failed Draft loads from presenting the default unsaved Strategy
  as though it were the requested Draft. Missing Strategy and missing Draft
  show their specific reason, while a Trashed strategy remains non-editable.
- Added cold-route, navigation and Browser API/Repository/MCP identity tests.

## Root Cause

The editor previously stored the selected Strategy only in React state. It
opened a Library row by `strategy_id`, but the URL remained `/`. Reloading
mounted the default unsaved editor and requested
`GET /strategy-lab/strategies/qqq-tqqq-sgov-dynamic-allocation/draft`.
That identity is not persisted in the local database, so the API correctly
returned `404 STRATEGY_NOT_FOUND`. The failed startup read left a misleading
error alongside the default editor. The Peak Draft API itself returned 200.

## Compatibility and Data Safety

V1.4.3 does not change Strategy semantics, Peak Drawdown, HOLD_PREVIOUS,
Backtest, Experiment, Selection, Freeze, Official OOS, Codex MCP permissions,
or the ChangeSet approval model. There is no schema migration, historical
StrategyVersion rewrite, hash change, or automatic Draft creation. Opening a
Draft remains a read/navigation action.
