# ETF Quant Research System v1.4.7

## Controlled Experiment / Grid Operator

Codex MCP can prepare and read a durable, bounded IS-only Grid configuration.
Preparation binds an exact immutable StrategyVersion ID and content hash to an
explicitly frozen ResearchProtocol, validates supported semantic targets and
parameter combinations, enforces a candidate budget, and performs cache-only
data availability preflight. It does not create an Experiment or run the Grid.

The local Experiment Builder presents the pending configuration for human
approval or rejection. Approval revalidates the frozen inputs and executes
through the existing canonical Grid service. Durable request identity and
execution leases support idempotent retry and recovery. Candidate Results can
be read through MCP after approval. The ParameterSet cross-space persistence
and Optimization Explorer cross-space read paths are also corrected, with
identity and integrity checks preserved. Browser and MCP cold-restart read-back
of the completed UAT Experiment passed.

Human Selection, candidate Freeze, and Official OOS remain separate decisions.
MCP has no direct Grid approve/run tool. This release does not add autonomous
optimization, automatic StrategyVersion creation, automatic Selection or OOS,
or real-money trading. No financial calculation or research-boundary semantics
were changed. The local Origin approval gate is not public-network user
authentication.

The Python package, frontend package, FastAPI application, and Operator
`backend_version` are aligned at 1.4.7. The independent bridge version remains
0.2.0. The release gate checks both consistency and the explicit target version.
